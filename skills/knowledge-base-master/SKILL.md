# 知识库管理与交互技能 (Knowledge Base Master)

## 1. 核心功能
- **持久化落盘**：所有知识条目结构化存储于 Markdown 文件中。
- **权重管理**：通过 YAML Frontmatter 或标签（如 `[权重: 高/中/低]`）定义检索优先级。
- **去重与清洗**：定期比对相似条目，合并重复语义，清理过期或冗余信息。
- **增删改查**：支持通过自然语言对底层 Markdown 进行原子化追加、精确替换或整段删除。

## 2. 数据结构规范
每个知识库文件采用以下格式：
```markdown
---
title: 击剑赛事知识库
version: 1.0.0
weight_default: 中
---

## [权重: 高] 赛事基本信息
- 时间：2026.11.28-30
- 地点：无锡太湖国际博览中心

## [权重: 低] 临时通知
- （待归档或清理内容）
```

## 3. 执行协议
当用户输入 `/kb` 或相关维护指令时，自动加载本技能，读取本地 `knowledge_base/` 目录下的知识图谱，执行权重排序、去重检查或内容增删落盘。
