## 一、 算力中枢与高可用引擎 (Power Pool & Failover)

### 1. 官方 OAuth 2.0 PKCE 借壳直通
* **免自建 GCP 门槛**：借壳官方桌面端公开 Client ID，配合 S256 PKCE 安全校验流，个人开发者无需申请繁琐的 GCP 企业认证与付费账单即可一键接入顶级大模型；
* **双模登录捕获**：
  * **回环自动监听**：内置 `127.0.0.1:1455` 回调截获引擎，浏览器授权后毫秒级静默入库；
  * **远程/指纹浏览器兜底**：支持直接粘贴回调 URL 或授权 code，适应远程桌面与无头服务器环境。

### 2. 毫秒级 429 故障转移与账号健康池
* **自动熔断切换 (<50ms)**：当主力账号遭遇 Google RPM/TPM 频率限制或 429 配额耗尽时，调度器在 50ms 内平滑漂移至算力池中下一个就绪账号，无感知断点续传；
* **令牌静默续期**：后台异步基于 `refresh_token` 自动换取最新 `access_token`，配合滑动窗口内存缓存，杜绝由于令牌过期引发的执行中断；
* **多模型与自定义接入**：全面兼容 Claude、OpenAI、DeepSeek 及本地 Ollama/vLLM 反向代理，支持跨厂商模型混部与动态切换。

## 二、 执行哲学重塑：「谋定而后动」意图对齐引擎 (v1.1.2 核心)

### 1. 输入维度降维（2 模式自适应）
* **`💬 对话模式 (只读澄清)`**：
  * 面向灵感推演、架构咨询与答疑；
  * 配备 **`[🧭 需求澄清 (Clarify)]`** 开关，遇到模糊提问先抛对齐选项，再做深度长文回答。
* **`⚡ 任务模式 (具身执行)`**：
  * 面向代码重构、脚本开发、系统运维等实体交付；
  * 配备 **`[⚡ 直接执行 | 📋 谋定而动]`** 策略胶囊。

### 2. 物理级 L0 只读硬门控（硬拦截）
* 传统方案往往仅靠 System Prompt 叮嘱模型“先别动代码”，大模型依然会手滑调用写工具；
* AgentHub 在 `plan_first` 阶段，底层引擎**物理隔离所有 L1/L2 破坏性写工具**（`write_local_file`、`execute_local_command`），仅挂载 `read_local_file`、`web_fetch` 等安全只读算子；
* 允许 Agent 静默勘探真实代码库与文件名，保证给出的方案绝非“纸上谈兵”，同时确保源码绝对安全。

### 3. 结构化交互对齐协议卡 (`interactive_inquiry`)
* **流式防抖骨架屏**：大模型输出 JSON 未闭合前自动显示脉冲加载态，彻底杜绝流式输出过程中的卡片闪烁报错；
* **组合决策表单**：一张卡片内原生融合单选、多选与自由填空；
* **Tab 键闪电跳跃填空**：填空模板采用标准 `{{参数:默认值}}` 语法，点击【填入输入框】后自动光标框选第一个占位符，按下 **`Tab` 键** 秒级跳转下一处待填项。

### 4. Approve & Act 方案审批与 Loop 无缝交接
* Agent 梳理出的方案步骤绝非聊天气泡中的“死文字”；
* 用户在界面点击 **【🚀 确认方案并启动执行】** 后，后端将该步骤清单自动持久化写入当前工作区的 **`.agenthub/scratchpad.md`**，解锁写权限并直接灌入外环引擎，开启全自动自愈推进。

## 三、 长程任务自愈循环与领航舱 (Task Loop Runner)

### 1. DAG 步骤自驱动状态机
* 遵循 *Anthropic Building Effective Agents* 评估循环规范：拆解任务 → 确定性算子调用 → 执行结果回显分析 → 动态修错重试；
* 支持长程大型工程的连续推进，告别“单次会话上下文溢出中断”。

### 2. 长程领航舱 (Loop HUD)
* 聊天顶部长驻沉浸式 HUD 状态舱，实时呈现当前循环的**总耗时、心跳节奏、当前运行子步骤与推演进度**；
* 支持随时一键【暂停任务】、【继续推演】或【提前中止】。

### 3. 敏感操作人类确认锁 (PolicyInterceptor)
* 针对删除文件、修改根目录配置、终止系统外部进程等高危行为；
* 引擎自动挂起并弹出高保真审批单，由用户进行物理授权后方可执行，兼顾极客自动化与资产安全性。

## 四、 硬件治理与桌面具身交互 (Hardware & UIA)

### 1. 宿主机硬件实时遥测 (SSE)
* 低功耗 Server-Sent Events 流式遥测 CPU 使用率、物理内存余量、GPU 负载与占用最高 Top 进程；
* 具备智能端口占用排查能力（一键检测 `8000` / `3000` 端口被谁占用，生成释放提案）。

### 2. Windows UI Automation (UIA) 原生控件穿透引擎
* **穿透自绘应用**：利用 Windows 底层 `UI Automation` 技术，原生穿透没有开放 API 的封闭桌面应用（如微信、钉钉、行业财务系统等）；
* **BFS 控件树提取**：自动抓取当前屏幕激活窗口的物理坐标、控件类名与无障碍节点；
* **双保险操作模拟**：支持原生 Patterns 点击与剪贴板中文防乱码粘贴（`^v`），实现真正意义上的“具身操控操作系统”。

### 3. 进程保护白名单机制
* 内置系统核心白名单（`explorer.exe`, `dwm.exe`, `system` 等及 AgentHub 自身）；
* 坚决禁止任何操作误伤操作系统关键驱动或发生自杀性中断。

## 五、 物理沙箱工作区与资产交付中枢 (Workspace & Library)

### 1. 独立工作区物理沙箱
* 支持按项目创建独立物理工作区（Workspace），工作区之间配置、环境变量、记忆画像完全隔离；
* 杜绝多项目混杂导致的上下文污染。

### 2. 资源管理器级资产库 (Library)
* **自动落盘登记**：Agent 编写的脚本、分析报告、导出的 Excel/CSV 自动索引登记；
* **三模随心切换**：
  * **网格大图标模式 (Grid)**：符合直觉的文件夹大卡片视觉，展示子文件夹与文件量；
  * **Windows 详细信息列表 (Table)**：按名称、类型、大小、修改时间排序展示；
  * **全部平铺总览 (Flat)**：一键看穿所有层级的深层资产；
* **一键本地交互**：支持在系统资源管理器中秒级打开目录或定位目标文件。

### 3. Canvas 沉浸式画布
* 聊天界面右侧一键唤出 Canvas 抽屉；
* 实时预览 HTML 网页应用、Mermaid 架构流程图与多语言代码文件，支持左右分屏边聊边调。

## 六、 技能生态与标准化扩展 (Skills & MCP)

### 1. 结构化四元组技能规范 (Skill-as-a-Folder)
* 每个技能采用自包含目录结构：
  ```text
  skills/<skill-name>/
  ├── SKILL.md          # YAML 描述头 + 标准 SOP 执行规程
  ├── tools/            # 确定性 Python 算子 (接收 JSON 入参并稳定返回结果)
  ├── knowledge/        # 领域知识文档 (由 SQLite FTS5 自动切块全文检索)
  └── schema.json       # 结构化输入/输出数据校验契约
  ```
* **分层加载机制**：L1 全局底座技能 + L2 工作区专属技能同名高优覆盖。

### 2. 内置母技能：`skill-creator`
* 当用户完成一段复杂的业务操作后，只需输入 `/new-skill` 或要求“把刚才的步骤沉淀为一个新技能”；
* 系统在 3 分钟内自动提取会话 SOP、生成工具脚本骨架并完成热加载。

### 3. Model Context Protocol (MCP) 原生热插拔
* 完美兼容 Anthropic MCP 协议标准；
* 开箱即用预装 Local Terminal Shell 与 SQLite FTS5 本地全文检索扩展，支持扩展任意外部 MCP 服务器。

## 八、 极客美学与绿色交付架构 (Design & Micro-Kernel)

### 1. 极客双模设计系统 (Dual-Theme Design System)
* **冷曜石墨黑 (Obsidian Emerald)**：深邃的石墨灰底色（`#0b0f0e`）搭配极具极客辨识度的翡翠绿微光；
