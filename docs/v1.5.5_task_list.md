  - [x] 1.2 创建 `backend/app/search/ast_chunker.py`：基于 `tree-sitter` 实现 Python/TS/JS/Go/Rust/Java/C++ 的完整类与函数边界切分及上下文面包屑头注入，兼容 Markdown 标题层级切分。

  - [x] 1.4 创建 `backend/app/search/hybrid_engine.py`：实现 SQLite `BLOB` 向量存取、NumPy L2 归一化矩阵点积、RRF 倒数排名融合、动态 Query 意图权重路由（符号查询 vs 自然语言查询）及低优先级后台异步增量向量化队列。
  - [x] 1.5 创建 `backend/app/search/light_graph_rag.py`：实现文档/切片入库三元组抽取器与基于 SQLite `WITH RECURSIVE` 的 2~3 跳子图扩展查询器，封装 `query_knowledge_graph` 工具。
  - [x] 1.6 创建 `backend/app/search/agentic_retrieval.py`：实现 `AgenticRetrievalLoop`（最多 `max_hops=3` 跳证据链覆盖度自检，检测未展开的附件或关联规则引用并自动改写 Query 发起二次/三次定向补全检索）。

- [x] **阶段二：多源知识冲突与时序权威仲裁 (`ConflictResolver`)**
  - [x] 2.1 创建 `backend/app/search/conflict_resolver.py`：实现入库 `authority_tier`（1=正式发布、2=工作区当前、3=草稿/归档）自动识别、业务生效时间戳 `effective_time` 正则提取、归一化主题簇 `topic_cluster_id` 生成及同主题旧版本 `is_superseded=1` 自动标记。
  - [x] 2.2 实现基于 `content_hash`（SHA-256）的本地与云端完全一致内容跨源索引合并去重。
  - [x] 2.3 在 `HybridSearchEngine` 重排阶段接入权威系数 $W_{\text{authority}} \in \{1.25, 1.00, 0.60\}$ 与时间新鲜度因子 $W_{\text{freshness}} \in \{1.20, 0.45\}$。
  - [x] 2.4 实现切片“时空身份证”元数据头部格式化器，并在检测到多份有效文档数值/条款矛盾时向上下文注入冲突显性披露系统提示词约束。

  - [x] 3.2 创建 `backend/app/vfs/wecom_drive.py`：实现企业微信微盘与文档知识库适配器（`access_token` 缓存自动刷新、目录树遍历、增量文件流拉取与智能文档导出）。

  - [x] 3.4 创建 `backend/app/vfs/document_extractor.py`：实现流式轻量解析器（基于 `pypdf` / `python-docx` / `openpyxl` 提取章节树并写入 `hybrid_chunks`，内存流用完即焚，零本地文件堆积）。
