# v1.5.5 代码审计整改与架构优化实施方案 (Implementation Plan)

## 一、方案背景与目标
针对 v1.5.5 代码审计（Standards & Spec 双轴）中发现的代码规范违规与功能规格偏差，本方案旨在消除架构违规、打通认知治理自审与置信度闭环、补齐缺失工具协议，并提升类型安全与代码整洁度。

---

## 二、整改模块与详细实施步骤

### 1. P0：认知治理与自审闭环实装 (`backend/app/agent/runtime.py`)
- **问题**：`evaluate()` 传入全空列表，自审检出冲突后未触发 Re-draft，低置信度 (<0.60) 仅发通知未形成阻断。
- **实施**：
  1. 真实采集 Agent 上下文中的 `retrieved_evidence`（检索返回的 chunk content 与 URI 列表）和 `tools_executed`（当前轮次执行过的工具名称与状态记录）。
  2. 若 `SelfCritique.critique(response)` 判定存在严重违规（未引用事实或数字冲突），且当前重试次数 `critique_retry < 1`，将批判意见作为内部反思反馈注入 Prompt 自动触发 1 次重新草拟（Re-draft）。
  3. 若 `ConfidenceEvaluator.evaluate()` 综合得分 `< 0.60`，触发阻断机制，将状态标记为挂起待审批或在事件流中输出明确的 HITL 确认卡点标识。

### 2. P0：多模态与浏览器工具协议注册 (`backend/app/agent/tool_protocol.py`, `backend/app/tools/`)
- **问题**：规格书 §4.4 定义的 `transcribe_audio_file`、`browser_inspect_page`、`browser_interact_action` 未在协议层注册，LLM 无法识别；`workspace_hybrid_search` 漏 `include_archived` 参数。
- **实施**：
  1. 在 `backend/app/agent/tool_protocol.py` 中注册 `transcribe_audio_file`、`browser_inspect_page`、`browser_interact_action` 的函数声明与 JSON 契约。
  2. 在 `backend/app/tools/browser_agent.py` 与 `backend/app/agent/runtime.py` 中完善上述工具的实际分发与执行逻辑。
  3. 在 `workspace_hybrid_search` 工具及底层检索方法中增加 `include_archived: bool = False` 参数支持。

### 3. P1：API 分层规范、类型注解与工厂抽取 (`backend/app/api/v1/knowledge.py`)
- **问题**：API 路由直接调用数据库连接执行 SQL 违反分层；多处路由函数缺少返回值类型注解；VFS 提供商构建存在重复分支。
- **实施**：
  1. 在 `backend/app/search/hybrid_engine.py` 中提供领域查询方法 `get_knowledge_stats()`，API 层禁止直接操作 SQL 连接。
  2. 为所有路由端点补齐显式返回值类型注解（如 `-> dict[str, Any]`）。
  3. 抽取 `create_vfs_provider(provider_type: str, config: dict) -> BaseCloudVFSProvider` 统一工厂函数。

### 4. P1：图谱向量起点定位与微经验双路召回对齐
- **问题**：图谱仅使用纯文本 `LIKE` 定位起点；微经验仅写入向量未在混合检索中融合召回。
- **实施**：
  1. 修改 `backend/app/search/light_graph_rag.py`，起点节点查找优先调用混合向量检索获取高相关节点，再做多跳子图遍历，`LIKE` 仅作回退。
  2. 修改 `backend/app/search/hybrid_engine.py`，增加微经验检索路由，按权重归一化合并回候选切片集。

### 5. P2：前端类型安全与构建产物清理
- **问题**：`CloudWikiMountModal.tsx` 使用 `useState<any[]>([])`；版本库包含 `frontend/out/` 静态构建产物。
- **实施**：
  1. 在前端定义显式 `CloudMountItem` 接口，替换 `any[]`。
  2. 验证并清理构建产物，确保版本管理干净。
